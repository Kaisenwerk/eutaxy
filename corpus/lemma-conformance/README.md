# Lemma conformance fixtures

The `accept/` and `reject/` fixtures of the Lemma language, copied from
[lemma-lang](https://github.com/jessealama/lemma-lang) at commit
`d1a89b0fe90df8be94da5f8a2eaf5f03038452bc`, unchanged, under its MIT
license (`LICENSE` here). Directory membership is the expectation: the spec
parser must accept every annotation under `accept/` and reject every one
under `reject/` (`tests/lemma-conformance.test.ts`).

To update, copy the two directories from a newer lemma-lang commit and
change the commit above.
