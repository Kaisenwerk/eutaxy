# @eutaxy/core

**Purpose.** The pure simulation kernel: effect log, fault model, seeded PRNG, `Platform` interface, schedulers, invariants including `refines`, shrinker, verdicts.

**Public surface.** `seedPrng`, `nextU32`, `nextFloat`, `nextInt` (pure PRNG); `emptyLog`, `appendEffect`, `serializeLog`, `digestLog` (effect log); `canonicalJson`; `utf8Encode`; scenario model (`ScenarioSpec`, `validateScenario`, `defaultBounds`, `PlatformData`); invariants (`checkInvariant`, `checkInvariants`, `selectEffects`, `getPath`, the `atMostOncePerKey` and `atLeastOnce` shapes and their constructors with `atLeastOncePerMessage`, which platforms wrap for their drives); fault model (`FaultKind`, `Schedule`, `decideFault`, and the ladders an effect's kind admits: `writeFaults`, `readFaults`, `decisionFaults`); the `Platform` and `RunHooks` interfaces (`RunHooks.bookkeeping` is the invocation a platform records its own actions under); verdicts (`ScenarioVerdict`, `describeVerdict`); shrink candidates (`shrinkCandidates`); `sameViolation`, `recomputePerMessageExpected`; state invariants (`EveryRow`, `Implies`, `Unique`, `StateQuery`, `RowCondition`, `queryRows`, `lastSnapshot`, `rowMatches`); `Platform.finish` and `RunHooks.snapshot` for end-of-run snapshots; `Platform.concurrent` and `RunHooks.running` for concurrent invocations; `Refines` and `decisionTarget` (the shell follows the core's recorded decisions, not on a stale read); `ScenarioSpec.specs`; spec verdicts (`SpecVerdict`: `Checked`, `Refuted` with its `Counterexample`, `SpecUnknown`; `describeSpecVerdict`); the enumeration model (`schedules`, `scheduleCount`: the schedules of a uniform tree of choices, depth first, whose claims in `schedules.props.ts` v0.8 proves with the proofs supplied in `schedules.props.lean`, and to which `engine`'s tests hold its enumerator).

**Self-check.** `self-check.ts` (not exported, never bundled) gives each invariant checker a form over plain data, built from small domains so values collide as in real logs, that runs the real checker and returns its keys and evidence. `self-check.props.ts` states that each agrees with a naive reference written there, sharing no code with the checkers: `atMostOncePerKey` and `atLeastOnce` (selectors anchored on a drawn effect, with `where` and `atLeast`), `everyRow`, `unique`, `implies`, `references` (rows drawn into snapshots of two targets, dot paths, `where` filters), every `RowCondition` on its own (`rowMatchesEach`), and `refines` (two invocations drawn as shapes with repeated reads and decisions, interleaved; a second property keeps only the state rule in play). `eutaxy report packages/core/src` runs them, and `tests/self-check.test.ts` plants bugs in a copy of these sources and requires each refuted.

**May import.** `@eutaxy/spec`. Only these are declared in `package.json`, and
pnpm links only declared workspace dependencies, so an import of any other
package does not resolve. The project references in `tsconfig.json` mirror the
list; a test keeps the two in sync with the design.

**Phase.** v0.4 onward. See `docs/design.md` and `docs/roadmap.md`.
