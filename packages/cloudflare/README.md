# @eutaxy/cloudflare

**Purpose.** Everything that knows about Cloudflare: binding proxies, the platform model, the binding allowlist, the Vitest integration.

**Public surface.** Scenario construction: `defineScenario`, `queue`,
`http`, `websocket` (connections opened through the Worker's `fetch` and handed to a Durable Object, their messages delivered inside it by its `webSocketMessage` handler; `webSocketReceived` selects the frames the object sent back), `rpc` (a `WorkerEntrypoint` driven by method calls, under the caller's
policy; `rpcResponse` selects the answers), `cron` (the ticks of a Cron
Trigger as events at their virtual time, with the declared re-runs of a
failed tick; `cron.ts` parses Cloudflare's dialect), `d1Schema`, `d1Write`, `d1Read`, `d1Param`, `atMostOncePerKey`, `atLeastOnce`,
`atLeastOncePerMessage`, `external`, `fetchCall`, `httpResponse`,
`durableObject` (with `alarmsPerObject`; key-value entries per object, and `sql` seeds for SQLite-backed objects: a schema and rows per table, run after the clear), `durableObjectTable` (one SQL table of an object at the end of the run, snapshotted as `<object>/<table>` beside the key-value rows), `r2Bucket` (an R2 binding, emptied and seeded before each run), `r2Op`, `workflow` (a Workflow binding and the class its instances run), `workflowStep`, `service` (a service binding with the callee scripted: method replies and `fetch()` replies; `serviceCall` selects the calls), `callee` (the Worker behind a service binding run for real, named by its module and wrangler config; the `name` in that config qualifies its bindings, `orders/DB`, in setup steps, targets, state queries and snapshots; `serviceCall` selects its calls too), `refines` (with the scenario's
`specs` naming the core's module, which is what records its decisions). Running: `createCloudflarePlatform` (D1 proxy, Durable
Object stub proxy with the `durableObjects` test helpers from
`cloudflare:test`, queue delivery with at-least-once semantics, inbound
request and RPC call delivery under the caller's retry policy (`caller.ts`,
`http.ts`, `rpc.ts`; `entrypoint.ts` constructs an entrypoint class outside the
runtime, and a `WorkerEntrypoint` default export's `fetch`, `queue` and
`scheduled` are its handlers, on an instance per invocation: `entrypointHandler`), Workflows as a model of
the engine running the scenario's own class (`exports`: the Worker
module's exports; `workflows.ts`), callees run for real (`callees`: each named Worker's name and module exports, and the `entrypoint` and `props` the caller's binding carries, which `ctx.props` holds; `callees.ts` hosts the callee's invocation inside the call through the engine's `hostInvocation`, its `env` a view of the scenario's under its own names; a callee's Workflow runs the callee's class with that view; `aliases` names the bindings that are a second name of another, read as that binding), R2 buckets (`r2.ts`), end-of-run D1,
Durable Object, R2 and Workflow snapshots), `check`, `expectHolds`, `runDifferential`. Each binding kind is one record in
`bindings.ts` (`d1Binding`, `r2Binding`, `durableObjectBinding`,
`workflowBinding`: recognise, proxy, clear, reset, snapshot, and for alarms
and Workflow runs the delivery of the binding's own events); the platform and
the differential runner iterate the records and know no kind by name.
State invariants: `d1Rows`, `durableObjectRows`, `r2Rows`, `workflowRows`, `everyRow`, `implies`,
`unique`, `references`, `queueAck`; `snapshotD1`.

**Effect conventions** (what the proxies record, and what selectors match):

| Target               | Op                                     | `call` payload                                                                                                                                                                                                                                                                                                 | `result` payload                                                                                                                                                                                   |
| -------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `D1:<binding>`       | `run`, `batch`                         | `{ args: { sql, params } }`                                                                                                                                                                                                                                                                                    | `{ args, result: { changes, lastRowId } }`                                                                                                                                                         |
| `Queue:<name>`       | `ack`, `retry`                         | `{ args: { messageId, body, implicit? } }`                                                                                                                                                                                                                                                                     | `{ args, result: { effective } }` (false when an earlier decision won)                                                                                                                             |
| `Queue:<name>`       | `background`                           | `{ args: { pending } }` after the handler returned, when `waitUntil` work exists; the only point that admits `cut_off`                                                                                                                                                                                         | `{ args, result: null }`                                                                                                                                                                           |
| `Fetch:<external>`   | the HTTP method                        | `{ args: { url, method, headers, body, dedupeKey } }`                                                                                                                                                                                                                                                          | `{ args, result: { status, effective, dedupeKey } }`; `effective` is false for a request replayed under a key the external had seen                                                                |
| `Queue:<name>`       | `dead_letter`                          | `{ args: { messageId, attempts } }` (invocation `platform`)                                                                                                                                                                                                                                                    | `{ args, result: null }`                                                                                                                                                                           |
| `Http:<path>`        | `response`                             | `{ args: { requestId, method, path } }` when the handler returned (or threw: then status 500); admits only `crash_before`, the response the caller never saw                                                                                                                                                   | `{ args, result: { status, ok, body } }`, body parsed when JSON, else text cut at 1000 chars                                                                                                       |
| `Http:<path>`        | `background`                           | as for queues, after the response                                                                                                                                                                                                                                                                              | `{ args, result: null }`                                                                                                                                                                           |
| `Http:<path>`        | `gave_up`                              | `{ args: { requestId, attempts } }` (invocation `platform`) when the caller's retries are spent                                                                                                                                                                                                                | `{ args, result: null }`                                                                                                                                                                           |
| `Rpc:<method>`       | `response`                             | `{ args: { callId, method, args } }` when the method returned or threw; admits `crash_before`, the answer the caller never saw, and with a caller deadline `ambiguous`; `Rpc:<Entrypoint>.<method>` for a named entrypoint                                                                                     | `{ args, result: { ok: true, value } }`, or `{ args, result: { ok: false, error } }` with the error's name and message when the method threw                                                       |
| `Rpc:<method>`       | `background`, `gave_up`                | as for `Http:<path>`, with `callId` in place of `requestId`                                                                                                                                                                                                                                                    | `{ args, result: null }`                                                                                                                                                                           |
| `Service:<binding>`  | `<method>`                             | `{ args: { args } }` for a call, `{ args: { property: true } }` for an awaited property; all four faults, as a Durable Object stub call                                                                                                                                                                        | `{ args, result: { value } }`, or `{ args, result: null, error }` for a scripted error                                                                                                             |
| `Service:<binding>`  | the HTTP method                        | `{ args: { url, method, headers, body } }` for `fetch()` through the binding; all four faults                                                                                                                                                                                                                  | `{ args, result: { status } }`                                                                                                                                                                     |
| `Service:<binding>`  | `<method>`, the HTTP method            | as above when the scenario names a callee for the binding; the effect hosts the callee's invocation `<caller invocation>/<binding>.<method>` (`#<n>` for the n-th call of that method from one caller invocation), whose effects are recorded under it; `crash_before`, `ambiguous`, `crash_after`, no `error` | `{ args, result: { value } }` or `{ status }`, or `{ args, result: null, error }` when the callee threw (the caller gets the error as RPC carries it) or crashed                                   |
| `Workflow:<binding>` | `wait`, `event`, `wait_timeout`        | `{ args: { instance, step, type, timeoutMs? } }`: a wait with no event starts (the instance suspends), receives its event (result `{ payload }`), or times out; the engine's own, no faults                                                                                                                    | `{ args, result }`                                                                                                                                                                                 |
| `Workflow:<binding>` | `send_event`                           | `{ args: { id, type, payload } }` from the binding's instance handle; all four faults, a call to the engine                                                                                                                                                                                                    | `{ args, result: null }`                                                                                                                                                                           |
| `WebSocket:<conn>`   | `open`                                 | `{ args: { connection, path } }` when the Worker answered the upgrade; no faults; on a 101 the client end is accepted and the server end found in the object                                                                                                                                                   | `{ args, result: { status, ok } }`                                                                                                                                                                 |
| `WebSocket:<conn>`   | `send`                                 | `{ args: { connection, object, message, data } }`: the scenario's message, handled inside the object (`webSocketMessage`); hosts the object's effects; `crash_before`, `crash_after`, `error` as an alarm                                                                                                      | `{ args, result: { delivered } }`; `delivered` false (no faults) when the connection never opened or the object had closed it                                                                      |
| `WebSocket:<conn>`   | `rebuild`                              | `{ args: { connection, object } }` (invocation `<message>/rebuild`) after a crash on a `send`: the dropped instance built again within the run, its constructor's effects hosted; no faults                                                                                                                    | `{ args, result: null }`                                                                                                                                                                           |
| `WebSocket:<conn>`   | `message`                              | `{ args: { connection, data } }` (invocation `platform`): a frame the object sent, recorded at the end of the run in arrival order; no faults                                                                                                                                                                  | `{ args, result: null }`                                                                                                                                                                           |
| `WebSocket:<conn>`   | `close`                                | `{ args: { connection, code, reason, by } }` (invocation `platform`): `by` is `object` when its handler closed the connection, `run` when the end of the run did; recorded after the frames; no faults                                                                                                         | `{ args, result: null }`                                                                                                                                                                           |
| `Cron:<expression>`  | `no_retry`                             | `{ args: { tick } }` when the handler called `noRetry()`; crash faults, as a queue ack                                                                                                                                                                                                                         | `{ args, result: null }`                                                                                                                                                                           |
| `Cron:<expression>`  | `background`, `gave_up`                | as for queues, with `tick` in place of `messageId`; `gave_up` when a failed tick's declared re-runs are spent                                                                                                                                                                                                  | `{ args, result: null }`                                                                                                                                                                           |
| `R2:<binding>`       | `put`, `delete`, `get`, `head`, `list` | `{ args: { key, onlyIf?, customMetadata?, httpMetadata? } }` for `put`, `{ args: { keys } }` for `delete`, the key and options for the reads; writes admit all four faults, reads all but `ambiguous`                                                                                                          | `put`: `{ args, result: { stored, size?, etag? } }` (`stored` false when `onlyIf` failed); `get`, `head`: `{ found, key?, size?, etag?, body? }`; `list`: `{ keys, truncated, delimitedPrefixes }` |
| `D1:<binding>`       | `snapshot`                             | —                                                                                                                                                                                                                                                                                                              | kind `snapshot`, `{ tables: { <table>: [rows] } }`, recorded after the last event                                                                                                                  |

An R2 bucket's snapshot is `R2:<binding>`, table `objects`, one row per
object `{ key, size, etag, customMetadata, httpMetadata, text? }` (`text`
for a UTF-8 object of up to 4 KiB). `r2Op(binding)` selects puts that stored an object (`result.stored`).
A committed write is a `result` record; `d1Write(binding)` selects results
with `result.changes` of at least 1.

**May import.** `@eutaxy/engine`, `@eutaxy/core`. Only these are declared in `package.json`, and
pnpm links only declared workspace dependencies, so an import of any other
package does not resolve. The project references in `tsconfig.json` mirror the
list; a test keeps the two in sync with the design.

**Phase.** v0.4 onward. See `docs/design.md` and `docs/roadmap.md`.
